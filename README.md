# 📊 이긍희 교수의 통계학 실험실

> **웹사이트 바로가기**: [https://databetter25.github.io/statlab/](https://databetter25.github.io/statlab/)

본 웹사이트는 생성형 AI 챗봇(Claude, ChatGPT, Gemini)을 활용하여 구축한 통계학 인터랙티브 학습 공간입니다.  
통계학의 역사부터 확률·추론 시뮬레이션, 용어 사전, 강의 자료까지 한눈에 살펴보고 실습할 수 있습니다.

사이트를 이용하시면서 오류를 발견하시거나 개선 의견이 있으시면 언제든지 [이슈(Issues)](../../issues) 게시판 또는 이메일로 제안해 주시기 바랍니다.

## 📑 목차 및 주요 콘텐츠

### 1. 📜 통계학의 역사
위키피디아와 다양한 역사적 문헌 자료를 바탕으로 통계학의 발전 흐름을 정리했습니다.
